## ✨ About Wandora

**Wandora** is a web-based accommodation listing platform designed to make discovering and sharing places to stay easier.

From hotels and rooms to cabins and unique stays, Wandora provides an interactive platform where users can explore properties, publish their own listings, and share their experiences through reviews.

The project combines server-side rendering, database management, authentication, image hosting, and location-based services into one application.

## 🚀 Features

- 🏡 **Explore Listings** – Discover different properties and accommodation options.
- 🔐 **User Authentication** – Secure user registration and login.
- ➕ **Create Listings** – Publish new accommodation listings.
- ✏️ **Manage Listings** – Edit and delete your own listings.
- 🖼️ **Image Management** – Upload and manage property images.
- ⭐ **Reviews & Ratings** – Share experiences and review properties.
- 📍 **Location Integration** – Location-based geocoding for property listings.
- 🛡️ **Authorization** – Restrict listing management to authorized users.
- 💾 **Database Integration** – Store and manage application data using MongoDB.

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Node.js | Runtime environment |
| Express.js | Backend framework |
| MongoDB | Database |
| Mongoose | Database modeling |
| EJS | Server-side rendering |
| Bootstrap & CSS | UI and styling |
| Passport.js | Authentication |
| Cloudinary | Image hosting |
| Mapbox | Geocoding |
| Multer | File uploads |
| Joi | Data validation |

## 🏗️ Application Architecture

Wandora follows a structured MVC-inspired architecture to keep application logic organized and maintainable.

| Directory | Responsibility |
|---|---|
| `controllers/` | Application logic |
| `models/` | Database models |
| `routes/` | Application routes |
| `views/` | EJS templates |
| `public/` | Static assets |
| `utils/` | Utility functions |
| `init/` | Database initialization |

Additional files handle application configuration, middleware, validation schemas, and cloud services.
